# SEO-агентство — правила для агента

Это репозиторий AI-first SEO-агентства. Архитектура: skills → projects → agent → data.

## Принципы

1. **Оркестрация по стоимости.** Дорогая модель думает (анализ, гипотезы,
   приоритизация). Тексты — модель подешевле. Парсинг, краулинг, обращения к
   API — Python-скрипты внутри `scripts/` каждого скилла. Никогда не парси
   страницы «своими руками» — для этого есть скрипты.

2. **Скилл = переиспользуемый актив.** Каждая рутинная задача оформляется как
   скилл в `.claude/skills/<name>/SKILL.md`. Описывай шаги словами; тяжёлую
   работу выноси в `scripts/`. Результаты — в `result/`.

3. **Данные клиента — в projects/.** Доступы, цели и параметры проекта лежат в
   `projects/<client>/config.json`. Не хардкодь их в скиллах.

4. **Проверяй, не выдумывай.** Любая рекомендация опирается на данные из
   `result/*.json`, а не на «мне так кажется». Нет данных — так и говори.

## Структура

- `.claude/skills/` — библиотека скиллов (общая для всех проектов).
- `projects/<client>/` — конфиг и данные конкретного клиента.
- `agent/` — оркестрация: планировщик, контроль бюджета (заполняется позже).

## Как добавить новый скилл

1. `mkdir -p .claude/skills/<name>/scripts .claude/skills/<name>/result`
2. Напиши `SKILL.md` с понятным `description` (от него зависит, сработает ли
   скилл — описывай триггеры явно, Claude склонен недотриггерить скиллы).
3. Вынеси тяжёлую работу в `scripts/`.
4. Закоммить в Git — скилл стал активом агентства.
