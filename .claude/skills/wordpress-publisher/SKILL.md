# Размещение черновиков в WordPress

Работай только через скрипты в `scripts/`. Бери адрес API и названия
переменных окружения из `projects/<client>/config.json`, секция `wordpress`.
Не записывай логины и пароли в репозиторий и не показывай их в выводе.

## Порядок работы

1. Найди проект и проверь секцию `wordpress` в его `config.json`.
2. Перед первой записью проверь подключение:

   ```bash
   python .claude/skills/wordpress-publisher/scripts/test_connection.py \
     --config projects/<client>/config.json
   ```

3. Подготовь JSON страницы. Обязательны `title` и `content`. Опциональны
   `slug`, `excerpt`, `parent`, `featured_media`, `meta` и `id`.
4. Создай новый черновик:

   ```bash
   python .claude/skills/wordpress-publisher/scripts/create_draft.py \
     --config projects/<client>/config.json --input page.json
   ```

5. Чтобы обновить существующий черновик, передай его ID через `--page-id`
   или поле `id` во входном JSON. Скрипт откажется менять опубликованную
   страницу без явного флага `--allow-published-update`.
6. Чтобы загрузить изображение:

   ```bash
   python .claude/skills/wordpress-publisher/scripts/upload_media.py \
     --config projects/<client>/config.json --file image.jpg \
     --alt "Описание изображения"
   ```

   Возьми возвращённый `id` и передай его как `featured_media` страницы.

## Ограничения безопасности

- Всегда принудительно сохраняй страницу со статусом `draft`.
- Не добавляй режим автоматической публикации.
- Не удаляй страницы или медиа.
- Не меняй опубликованную страницу без явного подтверждения пользователя.
- Перед записью покажи пользователю заголовок, slug и целевой сайт, если они
  не следуют однозначно из текущего запроса.
- Не передавай секреты аргументами командной строки; используй `.env` или
  переменные окружения.
- При ошибке авторизации остановись и сообщи код/текст ошибки без секрета.

## Входной JSON

```json
{
  "title": "Название страницы",
  "slug": "nazvanie-stranicy",
  "content": "<h2>Раздел</h2><p>Текст страницы.</p>",
  "excerpt": "Краткое описание",
  "parent": 0,
  "featured_media": 0,
  "meta": {}
}
```

Контент передавай как валидный HTML или разметку блоков Gutenberg. Не
вставляй в WordPress служебный блок с meta title/description как видимый
текст. Произвольные SEO-поля передавай через `meta` только если они открыты
для REST API установленным SEO-плагином.
