## Формат эталонной статьи (повторяем один в один)

- **H1**: «Как выбрать [товар] для [конкретная задача]» — не «топ-10», а гайд по критериям выбора.
- **Вступление**: почему выбор инструмента критичен для точности/допусков (IT6–IT8, Ra и т.п.).
- **4–5 разделов по критериям**: материал → геометрия → покрытия → системные факторы (жёсткость,
  биение) → практические рекомендации.
- **Сравнительная таблица** параметров вариантов.
- **Чек-лист** «перед заказом инструмента» — 7 пунктов.
- **Вывод** — 2–3 предложения.
- **Одна** контекстная ссылка на brotech.by с естественным анкором (в примере — «Фреза по металлу»
  → `/category/frezernaya-obrabotka/`). Не переспамить, ссылка одна за статью.
- Рубрика на площадке-доноре — что-то вроде «Tips» / «Советы».
- Объём 2000–2500 слов, экспертный технический тон с терминологией (Vc, Sz, Ra, Rz, СПИД).

- Силовые патроны — `/category/silovyye-patrony/`

Бренды (страницы поставщиков): Korloy, YG-1, Annway, Kemmler, Carmex, Teknik, Evoset,

проектирование оснастки) — `/services/`.
